# 核心只编排回合

框架核心只负责：解析角色定义与分身、读取会话、召回已绑定记忆、组装上下文、调用模型适配器、保存消息、通知记忆系统。

核心定义编排所依赖的存储接口，但模型厂商、数据库实现、HTTP/SSE、认证授权、UI、主动消息、调度、锁与队列实现、重试调度和具体记忆算法不进入核心。应用决定何时重试；核心仍按稳定的 `turnId` 识别同一逻辑回合，并在模型调用前恢复已经提交的权威回合。应用可以按自己的运行环境提供适配器或直接处理这些能力。

因此替换模型、存储或记忆实现不需要改角色定义，复制分身也不需要复制框架运行时。

可替换行为通过显式接口注入，不提供通用插件注册中心、任意生命周期 Hook 或可变全局上下文。需要动态发现和安装第三方扩展时，由应用在这些接口之外实现。
